# AmphiBot: amphibious snake robot example

A biomimetic amphibious snake robot for FarmSim: a head and 7 body segments
(0.56 m) joined by 7 yaw joints, with a free-rolling wheel under each
segment. It crawls on land, goes down a ramp and swims in a pool. It is
inspired by AmphiBot I (Crespi, Badertscher, Guignard and Ijspeert, EPFL
BioRob, Robotics and Autonomous Systems 50(4), 2005) and built from primitive
shapes only (no mesh files). MIT license, see LICENSE.

The documentation tutorials use this example:
https://podalanga.github.io/farmsim_docs/

## Run

With the FARMS packages installed:

```bash
# Built-in CPG network (farms_amphibious)
python run_sim.py --experiment_config experiment_config.yaml

# Custom travelling-wave controller with land/water gait switching
python run_sim.py --experiment_config experiment_config_wave.yaml
```

Results go to `Output/` (HDF5 log, options, MJCF), and the
centre-of-buoyancy lookup tables (if enabled) to `cob_lut_cache/`.

## Files

| File | Content |
|---|---|
| `models/amphibot.sdf` | The robot |
| `models/arena_ramp.sdf`, `models/water.sdf` | Land, 7.8 degree ramp, pool floor, and the water volume (visual) |
| `experiment_config.yaml`, `experiment_config_wave.yaml` | Experiments with the CPG and the custom controller |
| `simulation_config.yaml` | Timestep, duration, loggers, camera |
| `arena_config.yaml` | Arena and water (surface at z = 0, buoyancy, drag) |
| `animat_config.yaml`, `animat_config_wave.yaml` | Robot options, generated by `generate_config.py` |
| `controller/traveling_wave.py` | Custom controller |

Edit `generate_config.py` (gait, drag, motor gains) and rerun it rather than
editing the generated animat configurations.

## Origin

Ported from a Gazebo Harmonic version of the same robot. Gazebo models the
belly scales with anisotropic friction (`mu2`, `fdir1`), which MuJoCo does
not support, so this version uses passive wheels like the real AmphiBot I.
