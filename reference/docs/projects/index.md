# Projects using FarmSim

Real projects built on FarmSim, as case studies. Each one has its own
repository, robot models and experiments, and uses the FarmSim packages
documented in the rest of this site. Their pages show how the general
features combine in practice.

| Project | Robot | What it shows |
|---|---|---|
| [Zbot](zbot/index.md) | Eel-like underwater robot: a head, six segments and a tail | Swimming with the built-in CPG, a custom bout-and-glide controller, buoyancy tuning, a Docker workspace with the FARMS packages as submodules |

## Add your project

If you use FarmSim in a project, open an issue or a pull request on
[farmsim_docs](https://github.com/podalanga/farmsim_docs) with a short
overview page: the robot, what you simulate, and links to your repository
and publications. Project pages live in `reference/docs/projects/` and may
depend on their own repository, public or private; the rest of the
documentation must not depend on them.
